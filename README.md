# Language Translation Tool 🌍

## About Project

This is a simple web-based language translator application.

The user can enter text, choose a source language and target language,
and get the translated result.

## Features

-   Enter text to translate
-   Select source language
-   Select target language
-   Translate text using Translation API
-   Display translated text
-   Copy translated text
-   Text to Speech feature
-   Supports multiple languages

## Technologies Used

-   HTML
-   CSS
-   JavaScript
-   Translation API
-   Web Speech API

## Languages Supported

-   English
-   Hindi
-   Bengali
-   French
-   Spanish
-   German
-   Japanese
-   Korean
-   Chinese
-   Russian

## How To Run

1.  Download or clone the project.
2.  Open the project folder.
3.  Open index.html in a browser.
4.  Enter text and select languages.
5.  Click Translate.

## Working Process

1.  User enters text.
2.  Application sends text to translation API.
3.  API processes the request.
4.  Translated text is shown on screen.

## Purpose

This project is created for learning API integration and frontend
development.
